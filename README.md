# Практична робота: Багатопотоковість у C# (Клас Thread)

Програма для паралельного розрахунку факторіалів елементів масиву з використанням класу `Thread`.

## 📋 Завдання
1. Створити масив цілих чисел довжиною 20 елементів.
2. Присвоїти кожному елементу масиву випадкове значення від 1 до 12.
3. Для кожного елемента масиву в окремому паралельному потоці (`Thread`) розрахувати факторіал.
4. Після розрахунку вивести результат у консоль у форматі:
   `факторіал числа: {num}! = {numF}`
5. Після завершення роботи всіх потоків вивести:
   `Розрахунок закінчено.`

## 🛠 Реалізація
* **Генерація випадкових чисел:** `Random.Next(1, 13)` генерує значення від 1 до 12 включно.
* **Багатопотоковість:** для кожного елемента створюється та запускається окремий потік `new Thread(...)` і `.Start()`.
* **Синхронізація:** метод `thread.Join()` очікує завершення виконання кожного з 20 потоків перед фінальним виведенням повідомлення.
* **Тип даних `long`:** використовується для факторіалу, щоб запобігти переповненню чисел (наприклад, $12! = 479\,001\,600$).

## 🚀 Запуск проєкту
```bash
dotnet run
```
